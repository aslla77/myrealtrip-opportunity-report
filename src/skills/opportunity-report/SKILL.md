# opportunity-report — 데이터는 파이프라인, 보고서는 Codex가 작성

이 스킬은 **두 부분**이다. 순서대로 한다.

## 1부 · 데이터 생성 (결정론적 파이썬 — 그대로 실행)
```bash
python scripts/generate_data.py
```
- 입력: `data/*_arrivals_long.csv`(목적지별 출발국×월 입국통계). 없으면 중단 → `data/README.md`로 배치.
- **0단계 신선도 수집**: `collect_arrivals.py`가 목적지별 최신 월을 확인해, 정부 발표지연보다 뒤처진 소스만 공식 출처에서 재수집(자동 가능 소스만; PDF·인터랙티브는 수동 갱신 URL 안내). 최신이면 캐시 그대로 → 결정론 유지. 입국통계는 월별 갱신이라 '매일 새 데이터'가 아니라 '새 월치가 나오면 갱신'이다. 수집 실패는 캐시로 폴백(파이프라인 안 죽음).
- 산출(모두 `out/` 아래 새로 생성): 그림 `out/figs/opportunity_map.png`·`country_travel_heatmap.png`,
  분석 CSV들, 그리고 **`out/data_digest.md`(핵심 표·숫자 모음)**.
- 필요: pandas·numpy·matplotlib(`requirements.txt`). 순열검정 때문에 수 분 걸릴 수 있음.

## 2부 · 보고서 작성 (← 이건 **당신(Codex)이 직접 쓴다. 템플릿 복붙 금지**)
1. `out/data_digest.md`를 읽는다(모든 수치·표가 여기 있다). `out/figs/`의 두 그림도 확인.
2. 아래 구조로 **한국어 보고서를 당신이 작성**한다. 데이터를 **해석**하고 문장을 만들어라 — 표만 나열하지 말 것.
3. 보고서를 사용자가 원하는 위치(기본 `./travel_report/`)에 저장하고, `out/figs/*.png`를 그 옆에 복사해 상대경로로 참조한다.

### 보고서 필수 구조 (각 항목을 충분히 상세하게 — 짧게 쓰지 말 것)
- **요약 3줄**: 이번 기간의 핵심 기회와 한 줄 근거.
- **섹션 1 · 각 국별 많이 가는 여행지**: `country_travel_heatmap` 히트맵을 해석. 근접성이 어떻게 지배하는지, 한국의 목적지 편중, 각국 패턴(역내순환 등). 왜 이게 섹션 2의 기준선인지.
- **섹션 2 · 한국에게 열린 기회**: `opportunity_map` 기회맵 해석 + **후보 목적지마다 문단 하나씩** — 왜 기회인지(리드국 근거·거리·점유율 교차), 어떤 건 포화라 왜 제외했는지. "가까워서 뻔한 것"과 "멀지만 진짜"를 구분해 서술.
- **시점 관점**: 이 결과가 과거/미래와 어떻게 달라지는지(리드국 모멘텀은 계속 변함 → 주기 재실행의 가치). 새 월치가 발표되면 0단계 수집이 데이터를 갱신하므로 매 실행이 최신 기준.
- **한계·정직성**: 등급(입국통계=A / 직항시간=B·C), 패널 한정, 동조화가 기본·선행은 짧음.
- **MD 실행 제안**: 어느 목적지를 어떤 근거로 선제 편성·소싱할지 구체적으로.

### 작성 규칙 (반드시 지킬 것)
- **숫자는 `data_digest.md`에 있는 값만** 쓴다. 없는 수치를 지어내지 말 것.
- 랭킹은 **근거 붙은 가설**, 최종 편성 판단은 사람(MD)임을 명시.
- 그림 2장(opportunity_map·country_travel_heatmap)을 본문에 배치하고 캡션으로 "무엇을 보라" 설명.
- 분량: 각 섹션 여러 문단으로 **자세히**. (기존 템플릿 보고서가 너무 짧았던 걸 대체하는 게 목적이다.)

## 왜 이렇게 나눴나
데이터·통계는 **재현 가능해야** 하므로 결정론적 파이썬이 만들고(항상 같은 입력→같은 수치),
보고서 **서술·해석·제안**은 매번 데이터에 맞춰 새로 쓰여야 하므로 Codex가 작성한다. 그래서 "매번 똑같은 짧은 파일"이 아니라, 그때그때 데이터를 해석한 풍부한 보고서가 나온다.

## 근거·한계 규약
- 모든 수치는 공개 정부통계에서 **코드 재계산**(LLM 추정 아님). 좌표=공개 지리정보(A, 거리 결정론), 직항시간=항공시각표 대략치(B/C 라벨).
- 데이터 신선도: 0단계 `collect_arrivals.py`가 소스별 발표지연을 감안해 뒤처진 것만 갱신. 자동 불가 소스(PDF·인터랙티브 포털)는 수동 갱신 URL을 로그로 안내한다.
- 도시단위 통계 없음(전국 관문 근사)·패널 한정(미수집 지역 있음). 자세한 방법은 `references.md`.

## 검증 상태
- 데이터 파이프라인(`generate_data.py`→`digest.py`): 문법 확인됨. 실제 실행은 Codex 첫 실행에서 확인.
- `collect_arrivals.py` 자동 수집기(Malaysia·Singapore·Macao): 공식 엔드포인트 기준 작성했으나 **네트워크 응답 실측 검증 전** — 스키마 불일치 시 예외처리로 캐시 폴백(값 조작 없음). 첫 실행에서 검증할 것.
- `plugin.json`은 Codex 플러그인 규격 준수(로컬 마켓플레이스 설치·활성 확인됨).
